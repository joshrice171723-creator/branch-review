Let’s get you set up

First, choose the coding agent you want to use. We’ll check that it’s installed and signed in.

Checking connection…

Git is needed to open your project. Install it, then select Check connection.

Tell your agent about your project

For example: “Find the app I’ve been working on and help me open it here.”

Choose a folder instead

If you know where your project is, choose it directly.

What happens next?

Branch Review checks your setup and helps you choose a change to review. Nothing is merged or published during setup.

Don’t have a project yet? You can close this window and come back when it’s ready.

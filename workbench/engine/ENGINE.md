# Generic engineering engine

Version: generic-2.10.6.3.1-derived-0.2.0.

Read `TASK_EXECUTION_STANDARD.md`, `STANDARDS.md`, `PERFORMANCE.md`, and `REVIEW.md` in this directory. Apply them to the actual project and accepted request. This engine contains no assignment, product brief, application implementation, or external evaluation.

Read the project's instructions and accepted decisions. Identify external contracts and app-owned data before proposing schema changes. Preserve required behavior. Do not treat permission to change an owned schema as permission to change an external system.

Use the installed task workflow. Resolve required decisions before dependent work. Record the source of user answers. Do not select a suggested answer and claim user approval. Run relevant baseline checks and establish the project benchmark before implementation.

Follow the selected task mode. Audit changes no application code. Refactor preserves caller-visible behavior. Feature work changes only the agreed behavior. Build uses separately supplied requirements.

Use the internal review and repair loop. Record each repair round. Stop when current checks and review pass. If the configured limit is reached, stop and report remaining issues. Never claim a pass from missing evidence. Run explicit task finish only after the current completion gates pass.

Apply ASD-STE100 principles to prose. Keep normal programming identifiers. Formal compliance requires a separate check.
